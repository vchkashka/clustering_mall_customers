# Кластеризация покупателей

## Данные

Для работы был выбран датасет `Mall Customer Segmentation Data`, который предназначен для сегментации клиентов на основе их демографических и поведенческих данных. Цель — выявить однородные группы клиентов для разработки таргетированных маркетинговых стратегий, персонализированных предложений и оптимизации ресурсов. В него вхожят следующие признаки:
- `CustomerID` (числовой) - уникальный идентификатор клиента;
- `Gender` (категориальный) - пол клиента (Male/Female); 
- `Age` (числовой) - возраст клиента;
- `Annual Income` (числовой) - годовой доход клиента в тысячах долларов;
- `Spending Score` (числовой) - оценка расходов, которая присваивается на основе анализа поведения клиента (частота покупок, суммы чеков, возвраты и т.д.). Шкала от 1 до 100, где 1 - низкие расходы, 100 - очень высокие.

## Задача

Изучение алгоритмов кластеризации, приобретение навыков оценки качества разбиения данных на кластеры и интерпретации результатов.
